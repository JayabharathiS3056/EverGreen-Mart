# EverGreen Mart

A modern, premium and fully responsive organic supermarket landing page built using HTML5, CSS3 and Vanilla JavaScript.  
EverGreen Mart is designed to deliver a luxurious and immersive grocery shopping experience inspired by premium brands like Whole Foods Market and Thrive Market.

---

# 1. Project Overview

EverGreen Mart is a single-page supermarket website focused on:

- Organic lifestyle branding
- Premium UI/UX design
- Smooth animations
- Interactive sections
- Sustainable and modern aesthetics
- Mobile-first responsiveness

The website combines elegant visuals, storytelling and modern web interactions to create a cinematic organic supermarket experience.

---

# 2. Features

The project includes:

- Sticky transparent navbar
- Smooth scrolling navigation
- Full-screen hero section
- Animated counters
- Premium product cards
- Organic categories section
- Weekly offers section
- Infinite scrolling image gallery
- Customer testimonials
- Contact and newsletter section
- Responsive mobile menu
- Scroll reveal animations
- Hover interactions and glowing effects

---

# 3. Technologies Used

This project was built using:

- HTML5
- CSS3
- Vanilla JavaScript

Additional tools and resources:

- Google Fonts
- Font Awesome Icons

# 5. Website Sections

The landing page includes the following sections:

1. Hero Section  
2. About EverGreen Mart  
3. Featured Products  
4. Organic Categories  
5. Weekly Offers

# 7. How To Run The Project

### Step 1:
Download or clone the repository.

```bash
git clone https://github.com/your-username/evergreen-mart.git
```

### Step 2:
Open the project folder.

### Step 3:
Run the website by opening:

```bash
index.html
```

You can directly open it in any modern browser.
